Playrooms Co-op 1.1.0 and Playrooms New Game Plus 1.2.2 source.

Both mods
  Put the BepInEx core and interop assemblies for Playrooms in a "refs" folder at the top of this repo
  (from <game>\BepInEx\core and <game>\BepInEx\interop), then build each one:
    dotnet build PlayroomsCoop\PlayroomsCoop.csproj -c Release
    dotnet build PlayroomsNewGamePlus\PlayroomsNewGamePlus.csproj -c Release

Patcher (patcher\PlayroomsPatcher.csproj)
  Builds against a Playrooms install with BepInEx. Default path is the Steam Playrooms folder; change it with:
  dotnet build patcher\PlayroomsPatcher.csproj -c Release -p:GameDir="D:\SteamLibrary\steamapps\common\Playrooms"
